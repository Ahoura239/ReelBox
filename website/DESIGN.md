# Reelbox download page

## Direction

- **Product.** An independent Android film/series client with a device-local library and offline viewing, without accounts or subscriptions
- **Character.** Personal, quiet, cinema-dark
- **World.** A dark screening room and a private shelf of saved titles; graphite surfaces with the app’s existing coral accent
- **Moments.** The actual first-run interface, shown as a cropped host-rendered app capture; one coral download action
- **Signature.** A small bookmark outline, taken from the app’s private-library purpose

## Audit and treatment

This is a new page, not a reskin of an existing website. Avoided template defaults: no promotional badges, invented audience/ratings, emoji, gradients, glow, decorative AI imagery, stock movie posters, animation, tracking, external fonts or JavaScript. The screenshot is the real Flutter UI, not a fabricated device-playback claim. Its empty lower portion is cropped without removing controls.

1. Spacing: 4px rhythm, separate groups, 52px download control
2. Colour: neutral graphite shell; the original app coral only for the download action and bookmark mark
3. Icons: consistent 18px, 1.5-stroke line icons
4. Copy: short description, specific CPU/Android requirements, no playback or compatibility guarantees
5. Type: system sans-serif; 400/500 weights, monospace version metadata
6. Layout: asymmetric desktop split; text and action before app preview on mobile
7. Details: nested preview radii, keyboard skip link, visible focus states, checksum/source links
8. Visual: existing English first-run capture; no invented catalog data
9. Motion: colour-only hover feedback, disabled for reduced motion
